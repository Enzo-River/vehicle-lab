# 汽车拆装小工坊 · 3D 汽车原理乐园

给小朋友玩的 3D 汽车拆装游戏：把汽车拆开、看清每个零件，再动手把它装回去。

## 怎么玩

- **自由探秘**：点一点零件，它会从车上拆下来，同时弹出知识卡，讲清它叫什么、有什么用。
- **组装挑战**：所有零件散落在展台上，按住零件拖回蓝色框框的位置，全部装好会有星星和彩带。
- **运转演示**：车轮转起来、发动机抖动、挖掘机机械臂摆动、搅拌筒旋转、警灯闪烁。

## 收录车型（13 辆）

| 分类 | 车型 |
| --- | --- |
| 家用车 | 小轿车、跑车、越野车 SUV、皮卡 |
| 特种车 | 公交车、警车、消防车、救护车 |
| 工程车 | 挖掘机、推土机、起重机、搅拌车 |
| 农用车 | 拖拉机 |

每辆车 8～13 个可拆零件，共 130+ 个零件，全部带中文说明和工程小知识。

## 技术说明

- 纯静态页面，无需构建：Three.js（本地 vendor）+ ES Module。
- 车型零件用纯数据描述，运行时生成几何体，方便扩展新车型。
- 支持鼠标拖拽与触摸操作，桌面 / 手机 / 平板自适应。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```
